# Build notes: Rotozest WordPress → Next.js rebuild

Status as of 17 Nov 2026, branch `redesign`. This file records what was built, how it was checked, and what is left before launch.

## What this is
The new site for Rotozest Industries (SS / CI rotary gear pumps, Ahmedabad). It replaces the WordPress/Elementor site at www.rotozest.com. Goals: same content and Google rankings, better visuals, much faster loading. The old code in this repo (an unfinished Next.js 14 attempt) was removed. It is still in git history.

## Stack
- Next.js 16.4.6 (App Router, static pages, `trailingSlash: true`), React 19.3.1, TypeScript 5.9.3, Tailwind CSS 4.3.5.
- Fonts through `next/font`: Barlow Semi Condensed (headings) and Heebo (body), self-hosted.
- Images through `next/image` (AVIF/WebP). Icons from lucide-react.
- Tracking through `@next/third-parties`: GTM `GTM-55ZFLFT4` and GA4 `G-GLK4YTC4EE`, loaded after the page is interactive. Toggles are in `src/lib/site.ts`.
- Email through Resend (`src/lib/mail.ts`): inquiry, careers (CV upload) and the brochure email (branded template in `src/lib/email/brochure-email.ts`).
- 3D: three.js 0.187 plus three-bvh-csg. It only loads on the SS pump page, and only after a click.

## Pages and SEO parity
- All 18 real WordPress URLs are kept with a trailing slash: home, about-us, ss/ci pump pages, applications, careers, blog, contact-us, 7 SEO landing pages, 3 blog posts and category/industry.
- Titles, descriptions, canonicals, robots meta, H1s, heading order, FAQ text and every JSON-LD block were copied from the scrape (`docs/migration/`).
- Organization, LocalBusiness and BreadcrumbList were added site-wide.
- Redirects in `next.config.ts`: theme junk and legacy URLs return 308 to the closest page; old `/wp-content/uploads/*` images redirect to the new files. The brochure keeps its URL `/wp-content/uploads/2025/06/rotozest-brochure.pdf`.
- `sitemap.xml`, `robots.txt`, `manifest.webmanifest`, favicon/icon/apple-icon and per-page 1200×630 OG images (`public/og`, built by `scripts/og-images.mjs`).

## Features added on top of the old content
- The gear loader ("dial") is kept as a short first-visit brand moment. It never blocks content and respects reduced motion.
- "Inquire Now" everywhere (never "quote"). An inquiry popup opens on a timer, on scroll depth, or on exit intent, and shows phone and WhatsApp on one line.
- Brochure download asks for an email and sends an automated branded email with the PDF.
- Counters 525+ / 500+ / 25+ / 100%.
- Core Values as an auto-moving carousel.
- "Why Choose Rotozest?" as 4 icon cards.
- Distinct icons for the "How does it work" steps.
- Back-to-top arrow and mobile action bar.
- Subtle reveal and hover motion, with a fail-safe so content never stays hidden.
- Map loads only on click (facade).
- Interactive 3D model of the SS rotary gear pump on `/ss-rotary-gear-pump/` (see below).

## The 3D pump model
- Code: `src/components/pump3d/scene.ts`, with a lazy wrapper in `src/components/Pump3D.tsx`.
- Every dimension and part is traced to a product photo in `docs/3d-pump-spec.md`. That file also logs each review round and each correction you made.
- Drawings: `docs/3d-review/component-sheet.png`, generated by `scripts/component-sheet.py`.
- Review history: 5-persona review, then a 25-persona review (5 rooms × 5 personas, one photo per room). Before/after renders are in `docs/3d-review/rooms/` and `docs/3d-review/review-v5-rooms.png`.
- Latest confirmed geometry:
  - Front flange 20 long; plate is a 15 mm slab plus a 7 mm boss.
  - Pear-shaped plate opening (O over 0).
  - 2 plate bolts on the body axis, in line with the axial tapped holes in the flange back face (both sides).
  - Round cast cover flange with 4 acorn nuts at ±30 / ±31.
  - U base with a solid first half, 4 holes, and gussets from 34 mm down to 0.
- Look:
  - Etched markings are solid matte black. The RZ mark uses the logo SVG, which now has an intrinsic size of 3200 × 868 so it renders sharp.
  - Cast cover is bead-blasted grey; nuts and bolt heads have crisp hex flats.
- Still open: split lock washers, single vs double oblong outline, the exact 15 mm shaft offset, the exact cast-box width.

## Local tools
- `npm run start:3100`: production server on port 3100.
- `npm run share` / `npm run tunnel`: Cloudflare tunnel to develop.trueorfalse.dev. It reads `CLOUDFLARE_TUNNEL_TOKEN` from `.env.local`, which is gitignored; a copy is in the secrets vault. In the Cloudflare dashboard the hostname's service must be **HTTP** `localhost:3100`.
- `.claude/launch.json`: preview configs `rotozest-prod` (3100) and `rotozest-dev` (3101).
- `scrape/` (gitignored) holds the raw WordPress scrape that `seo:diff`, `images` and `content` read.
